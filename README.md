# Woongjin_KDT_final_project


## 웹 트래픽 분석 & 캠페인 효과 모니터링 (2025.10.01–10.22)

###  목표  
캠페인 전후 웹 트래픽 변화를 분석해,  
유입 구조 · 콘텐츠 소비 패턴 · 시간대별 이용 행태를 시각적으로 비교하고  
브랜드 인지도 캠페인(**Brand Awareness**)과 매출형 캠페인(**Autumn Sale**)의 성과와 한계를 도출함.

##  EDA 주요 결과

### 1️⃣ 전체 트래픽 구조
- 캠페인 종료 후 **Direct 유입 비중 상승**, **Paid 유입 급감**
- **Organic 채널**은 꾸준히 유지 → **콘텐츠 기반 유입 증가**
- Paid 캠페인 효과는 명확히 종료 시점에서 급감 확인됨

### 2️⃣ 유입 소스별 변화
- **YouTube (Brand Awareness)** 중심의 Paid 트래픽이 캠페인 기간 중 가장 높았음 (최대 42%)  
- 이후 **Direct**, **Naver**, **Instagram** 유입이 늘며 **자발적 방문 구조로 전환**

### 3️⃣ 페이지 카테고리별 변화
- **Post-campaign** 시점에 **블로그(blog)** 콘텐츠 유입이 확연히 증가  
  → 브랜드 인지도 이후 **탐색·정보 소비형 행동**으로 전환  
- **Product 페이지** 트래픽은 감소, **Event 페이지**는 종료 직후까지 피크 유지

### 4️⃣ 요일·시간대별 패턴
- **오전 9–11시** 집중 트래픽 구간 → 캠페인 전후 동일하게 유지  
- **오후 17–19시** 2차 피크 발생  
- **수요일 트래픽** 유독 높음 → 업무 리듬(중간 보고일/내부 홍보일) 가능성  
- **주중 트래픽 > 주말 트래픽** 일관 유지

##  인사이트 분석

### ▶ Brand Awareness (YouTube 중심 캠페인)
- **오전 9–11시 확실한 피크**  
  → 광고 노출 타이밍이 근무 시간대에 집중됨  
- **12시 이후 급감**, **18시 이후 거의 없음**  
  → 주요 이용층은 **직장인·탐색형 유저**  
- **인지도 노출엔 성공**, 그러나 **전환·심화 탐색 부족**

### ▶ Autumn Sale (단기 매출형 캠페인)
- **즉각적인 트래픽 상승 효과**, **지속성은 제한적**
- 캠페인 종료 후 유입 급감, 재방문율 낮음

### ▶ Post Campaign (자연 유입 중심)
- **Direct 비중 증가**, **Paid 급감**
- **콘텐츠형 페이지(blog/company)** 노출 점진적 증가  
  → 광고 → 탐색 → 정보 소비의 흐름 전환  
- **오전 집중 패턴** 유지 → **업무시간 기반 트래픽 구조**

##  비즈니스 제언

1. **브랜딩 → 탐색 흐름 강화**  
   - 유튜브 랜딩 → 블로그·제품 페이지 자연스러운 전환 설계  
   - 랜딩 페이지 내 **콘텐츠 큐레이션 영역** 강화  

2. **검색 확장 (SEO 전략)**  
   - Direct 유입 대비 Paid 트래픽 의존도 개선  
   - 블로그·문서 중심 **SEO/AI 검색 노출 강화**

3. **시간대 기반 크리에이티브 운영**  
   - **09–11시** 집중 소재 테스트 및 광고 AB 실험  

4. **캠페인 종료 후 리마케팅 설계**  
   - 탐색 유저 대상 **콘텐츠 기반 재유입 리타겟팅** 구조 도입

##  결론

- **캠페인 종료 후에도 트래픽 유지** → 브랜딩 효과 존재  
- 그러나 **Paid 중심 유입 구조 의존**이 뚜렷  
- **Autumn Sale**은 단기 성과형, **Brand Awareness**는 인지도 확보형  
- 향후 과제는 **SEO 강화**, **UTM 정합성 개선**, **내부 전환 경로 최적화**
